Template Registration API:


About API

These APIs allow you to interact with systems and access our services seamlessly. They enable you to perform tasks such as:
Header, Content Template, and Consent Template Registration: Register Headers, Content Templates, and Content Templates without logging in to the DLT portal via our APIs.
Callback: By utilizing callback URLs, you can receive real-time updates on the approval status of Headers, Content Templates , and Consent Templates registered through the APIs.
Real time status updates: Keep track of changes in the global status of your Headers and Templates without logging in to the DLT portal.
Trubloq registration APIs provide a comprehensive set of functionalities, encompassing all aspects of DLT portals and providing real-time status updates.
Functionalities provided in the API
Register a new Header
Register a new Content Template
Link or De-Link Headers to a Content Template
Mapping Consent Template to Content Templates
Register a New Consent Template
